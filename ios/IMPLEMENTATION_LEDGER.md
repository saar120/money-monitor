## Update rules

- Update this ledger in the same change that starts, completes, blocks, or materially changes a task.
- `Done` requires linked acceptance evidence; implementation alone is not sufficient.
- `Blocked` names the missing decision or external dependency and the next unblocking action.
- The detailed phase specification remains canonical for scope and acceptance criteria.
- New architectural decisions are recorded in [DECISIONS.md](Documentation/DECISIONS.md) or a linked ADR.
- Dates use `YYYY-MM-DD`; evidence should be reproducible without secret or financial payloads.

## Accepted implementation defaults

| Area               | Baseline                                                                                                                                                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor              | One Mac owner; multiple individually approved personal iPhones; no household roles.                                                                                                                                                                         |
| Exposure           | Mobile Access is opt-in. Desktop operation never depends on Tailscale availability.                                                                                                                                                                         |
| Server isolation   | A separate mobile-only Fastify instance binds to `127.0.0.1`; it does not register desktop routes, dashboard assets, schedulers, Telegram, scraping commands, or Advisor.                                                                                   |
| Transport          | A Money Monitor-owned Tailscale Serve HTTPS listener targets only the mobile server and is reconciled after restart/wake. Unrelated Serve configuration is never reset.                                                                                     |
| Pairing            | Random single-use QR proof, five-minute expiry/approval timeout, explicit Mac approval, and a separate 256-bit claimant secret for polling and idempotent single-mint exchange.                                                                             |
| Device token       | Opaque 256-bit token is persisted raw only in iOS Keychain and digest-only on Mac. Delivery retries from expiring process memory; approved re-pair atomically rotates the same device identity, and rotation/revocation invalidate prior access.            |
| Capability         | `mobile.read` only for the read-only MVP. Newly added mobile routes are denied until classified.                                                                                                                                                            |
| Identity/version   | Canonical stable UUID `serverId`; independent protocol/API/bootstrap schema v1. Successful bootstrap reports client-version compatibility as `not_evaluated` until a client version reaches the server; explicit incompatibility remains a data-free `426`. |
| Snapshot coherence | One `calculatedAt` and explicit Asia/Jerusalem `financialDate` cover Home, budget, review, and future-row filtering; partial or unknown-cacheability payloads never replace saved data.                                                                     |
| Revocation         | Connected requests fail immediately after revocation. A Mac cannot erase an offline iPhone; Phase 1 defines cached-data retention and lock behavior.                                                                                                        |

- Phase 4 command capability matrix.
- Production organization identifier, bundle identifier, signing team, and distribution lane.
- Notifications, household roles, cloud transport, and multi-Mac behavior.
